# AlSat Yeri | Quick Start

Proje `client` ve `server` olarak ikiye ayrılmıştır.

## Tek Komutla Çalıştırma (Önerilen)

1. Bağımlılıkları kurun:
   ```bash
   npm run install:all
   ```
2. Her iki sunucuyu da başlatın:
   ```bash
   npm run dev
   ```

## Ayrı Ayrı Çalıştırma

### Backend (Server)
```bash
cd server
npm install
node server.js
```

### Frontend (Client)
```bash
cd client
npm install
npm run dev
```
